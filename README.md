# HTML-Webpage-
An HTML is a document written in HyperText Markup Language (HTML), which is the standard language for creating and structuring content on the web. It uses tags (like &lt;h1>, &lt;p>, &lt;img>, &lt;a>) to define headings, paragraphs, images, links, and other elements.  Browsers read HTML files and render them into a visual format for users.
